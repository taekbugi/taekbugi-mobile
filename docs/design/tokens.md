# 디자인 토큰 (StyleGuide 요약)

> 출처: 정본 캔버스 `project/StyleGuide.dc.html` 및 각 화면의 인라인 스타일 (2026-11-23).
> 값이 캔버스와 다르면 캔버스를 따르고 이 문서를 고칩니다.
> 코드에서는 이 값을 **한 곳**(Android `TaekbugiTheme` / iOS `TaekbugiTokens`)에만 정의하고, 화면 코드에 hex를 직접 쓰지 않습니다.

## 배송 상태 칩 · 라인 아이콘

| 상태 | 배경 | 글자 | 라인 아이콘 (홈 목록) |
|---|---|---|---|
| 집하 전 | `#F1F2F4` | `#596069` | 시계 |
| 이동 중 | `#FFF3E6` | `#9A5B13` | 상자 |
| 배송 출발 | `#EAF3E4` | `#2F6420` | 트럭 |
| 배송 완료 | `#F1F2F4` | `#191B1F` | 체크(원) |
| 조회 지연 | `#FDECEA` | `#B42318` | (디자인 확인 필요 — G-03) |

칩: `padding 3~4px × 9~10px`, `radius 999`, `12px / 600`.
아이콘: **1.8px 라인 아이콘**(Lucide 계열 형태), 20px. 이모지 금지.

## 그림자 · 모서리

테두리 대신 **그림자**로 카드를 구분합니다.

| 단계 | 모서리 | 그림자 | 용도 |
|---|---|---|---|
| Low | 14 | `0 1 2 rgba(17,24,39,.04), 0 2 8 rgba(17,24,39,.05)` | 버튼, 아이콘 버튼 |
| Mid | 20 | `0 1 2 rgba(17,24,39,.04), 0 4 16 rgba(17,24,39,.06)` | 리스트 카드 |
| High | 22~24 | `0 1 2 rgba(17,24,39,.04), 0 8 28 rgba(17,24,39,.08)` | 히어로 카드, 위젯 |
| Primary glow | 14~16 | `0 4 14 rgba(63,122,42,.25)` | 주요 버튼 |
