# 0006. 백엔드 API 연동 보류

- 상태: Accepted (사용자 지정, 2026-11-23)

## 결정
- 백엔드 API 문서가 `docs/api/specs/`에 들어오기 전에는 **서버 연동 코드를 만들지 않습니다.** 엔드포인트 경로, 요청·응답 필드, 인증 토큰 형식, 오류 코드, 페이지네이션을 추측하지 않습니다.
- 금지: `shared/data/**/remote/server/**` 파일 생성(훅으로 차단), 서버 DTO, 가짜 base URL, 서버 응답을 흉내 낸 Mock 서버.
- 허용: 기획·디자인만으로 정해지는 것 — 화면, 로컬 저장, 택배사 직접 조회(레시피), 로컬 알림. domain 포트는 **제품 요구로 정해지는 모양**일 때만 정의하고, 구현은 로컬 전용 또는 미구현(`BLOCKED_API`)으로 둡니다.
- 레시피 **형식**(해석기가 읽는 JSON)은 모바일이 초안을 쓰되 백엔드와 합의 전까지 `docs/architecture/recipe-format.md`에 Draft로 둡니다(Q-06). 레시피를 서버에서 **받아 오는** 코드는 API 문서 이후입니다. 그 전에는 번들 레시피를 씁니다.

## API 문서가 오면
`/api-onboarding` 스킬 순서대로 진행합니다: 원문 보관 → 계약 요약 → 기획·디자인과 차이 보고 → ADR → 구현.
