# 레시피 형식 (Draft)

- 상태: **Draft** — 모바일 해석기 기준 초안. 백엔드 합의 전까지 바뀔 수 있습니다 (Q-06, ADR-0006).
- 작성 시점: F-02. 그 전에는 이 문서를 채우지 않습니다.

## 지켜야 할 것 (기획 5장)
- 선언형 JSON만. 코드 다운로드·실행 금지 (스크립트, 정규식 이외의 표현식 언어 금지)
- Ed25519 서명 검증을 통과한 레시피만 실행. 공개키는 앱에 내장, 비밀키는 저장소에 넣지 않음
- 요청 대상은 앱에 내장된 택배사 도메인 허용 목록 안의 `https` URL만
- `min_interpreter_version`보다 낮은 해석기는 해당 레시피를 건너뛰고 마지막 성공 레시피를 씀
- 마지막으로 성공한 레시피를 캐시

## 초안 구성 (F-02에서 작성)
- 메타: `carrier`, `version`, `min_interpreter_version`
- 단계(`steps`): HTTP 요청, 쿠키·토큰 추출, JSON 경로 / CSS 셀렉터 추출
- 매핑: 원본 상태 → `DeliveryStatus`, 위치 정규화(시·구), 버릴 필드
- 서명 대상 바이트 정의(정규화 방식)
