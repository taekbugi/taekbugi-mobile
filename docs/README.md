# 문서 지도

README.md, AGENTS.md, CLAUDE.md를 뺀 모든 문서는 이 폴더에 둡니다.

| 폴더 | 내용 |
|---|---|
| [`product/`](product/) | 기획서 원문(`mvp-spec.md`), 기획↔디자인 불일치(`spec-design-gaps.md`), 확정 필요 항목(`open-questions.md`) |
| [`design/`](design/) | 디자인 정본 링크·화면 목록(`README.md`), 토큰(`tokens.md`) |
| [`architecture/`](architecture/) | 구조 개요, 레시피 형식, ADR |
| [`features/`](features/) | 백로그, 기능 명세(`F-XX-*.md`), 템플릿 |
| [`testing/`](testing/) | 테스트 전략과 규칙 |
| [`qa/`](qa/) | QA 절차, 보고서 템플릿, 보고서(`reports/`) |
| [`api/`](api/) | 백엔드 API 문서(`specs/`, 현재 비어 있음)와 계약 요약 |
| [`carriers/`](carriers/) | 택배사 분석 노트(클린룸) |
| [`setup/`](setup/) | 개발 환경 |
| [`workflow/`](workflow/) | 에이전트 작업 흐름 |

새 문서를 만들 때는 위 폴더 중 맞는 곳에 두고, 맞는 곳이 없으면 하위 폴더를 새로 만든 뒤 이 표에 한 줄 추가합니다.
