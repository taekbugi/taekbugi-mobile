# 백엔드 API 규칙 (항상 적용)

- `docs/api/specs/`에 백엔드가 준 API 문서가 들어오기 전에는 **서버 연동을 시작하지 않습니다** (ADR-0006).
- 추측 금지 대상: 엔드포인트 경로, base URL, 요청·응답 필드 이름과 타입, 인증 방식(JWT 여부, 토큰 갱신), 오류 코드, 페이지네이션, 동기화 방식, 지표 보고 형식, 레시피 배포 API.
- 기획서 6장의 Django 모델(`Parcel`, `ParcelTombstone` …)은 백엔드 내부 설계입니다. 이걸로 DTO·API 클라이언트를 만들지 않습니다.
- `shared/data/src/**/remote/server/**`는 문서 도착 전 생성 금지(훅이 차단). 다른 경로에 같은 역할의 코드를 만들어 우회하지 않습니다.
- 허용: 기획·디자인만으로 정해지는 화면, 로컬 저장, 택배사 직접 조회, 로컬 알림. 서버가 필요한 동작은 domain 포트까지만 두고 구현은 `BLOCKED_API`로 남깁니다.
- 로그인·이메일 코드 화면은 화면과 입력 검증까지만. "코드 받기"를 누른 뒤의 동작은 API 문서 이후입니다.
- 문서가 오면 `/api-onboarding` 스킬을 따릅니다.
